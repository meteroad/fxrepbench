# Contributing

FXRepBench tracks are versioned evaluation contracts. Changes to code may be
backward compatible, but published manifests and metric definitions are
immutable within a release.

For a proposed change:

1. state whether it changes data, rendering, metrics, or documentation;
2. add or update an integrity test;
3. report the affected track and version; and
4. never replace a published manifest in place.

Do not commit downloaded audio, reconstructed audio, model checkpoints,
credentials, internal data metadata, or absolute machine paths.
